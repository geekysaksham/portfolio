# Portfolio

A responsive personal portfolio website built using HTML and Tailwind CSS. This portfolio showcases my projects, technical skills, and learning journey with a clean, modern, and user-friendly design.

## 🚀 Features

- Responsive Design
- Modern & Clean UI
- Projects Showcase
- Skills Section
- About Me Section
- Contact Section
- Smooth Navigation

## 🛠️ Built With

- HTML5
- Tailwind CSS
